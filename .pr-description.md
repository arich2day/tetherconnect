# Tether marketing-site rewrite — v1 + v2 (review-panel pass)

## Summary

Full rewrite of the marketing site against the BRIEF and approved RECONCILIATION PLAN. The new site is organized around the five-beat narrative spine — Reality / Spec / Mechanism / Outcome / Action — with one page per beat home, and only BUILT or honestly-scoped PARTIAL capabilities on the site. Every concrete capability claim points at a `path:line` on `origin/master` of `arich2day/project-tether`. The site loses the patent-moat / "stops AI data leaks" / "MITM payload inspection" / "100% egress coverage" / "flat rate" / "system-wide HTTPS" claims and gains a written security-disclosure policy, a coexistence table for EDR / CASB / IdP / DLP, three-tier judge authority, and per-request attestation via `X-Tether-Policy-Version`.
